# 📝 React To-Do List

A simple and elegant To-Do List built with React. Add, delete, and manage your daily tasks with ease.

## 🚀 Features

- Add tasks
- Delete tasks
- Checkbox for task completion (UI only)
- Responsive design

## 🛠 Tech Stack

- React (with Hooks)
- HTML & CSS
- VS Code
